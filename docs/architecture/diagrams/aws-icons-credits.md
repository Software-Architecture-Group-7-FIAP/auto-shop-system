# Créditos dos ícones AWS

O arquivo aws-icons.json contém apenas os ícones necessários ao diagrama de arquitetura. Eles foram extraídos de @aws-icons/iconify 4.1.0, pacote baseado nos AWS Architecture Icons e versionado junto com o projeto para renderização local.

A AWS permite que clientes e parceiros usem os AWS Architecture Icons para criar diagramas de arquitetura. Consulte [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) e [@aws-icons/iconify](https://www.npmjs.com/package/@aws-icons/iconify).
